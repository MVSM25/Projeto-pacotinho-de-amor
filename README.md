# Pacotinhos de Amor — site

## Estrutura
- `index.html` — página e estrutura do site.
- `style.css` — layout, responsividade e paleta inspirada na logo.
- `script.js` — cadastro dos animais, busca, abas/seções e modal de detalhes.
- `assets/logo.jpg` — logo fornecida para o projeto.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets`.
3. Em **Settings → Pages**, selecione a branch principal e a pasta `/root`.
4. Salve. O GitHub Pages publicará o site.

## Como colocar fotos dos animais
O cadastro já possui o campo `foto`. Exemplo:
`"foto": "assets/animais/julinho.jpg"`

Depois, coloque o arquivo de imagem no caminho indicado.

## Observação sobre os dados
As histórias, idades e características foram organizadas a partir dos materiais fornecidos no projeto. Os campos de guia/cercado e entrevistadoras da tabela não foram incluídos no site, conforme solicitado.
